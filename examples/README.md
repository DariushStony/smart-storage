# Examples

- [vanilla-js/](./vanilla-js/): one page that uses the built bundle with real
  `localStorage`: TTL, `extend`, `stats()`, the raw stored string, and
  catching `StorageQuotaError`.

- [cookie-driver/](./cookie-driver/): a complete custom storage driver built on
  `BaseStorageDriver`, registered by name and verified with the conformance kit.

Each example's README explains how to run it.
